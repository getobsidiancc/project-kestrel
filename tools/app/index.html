Calibrate

Measures how fast the game turns at each stick position, so mouse moves come out exact. Stand somewhere safe in-game, don't touch the mouse during a test. F12 on the adapter's keyboard works as the button, so you can stay on the game screen.

Measuring

1 · Where the stick starts moving

Start: the stick creeps forward very slowly. Press the second button (or F12) the moment the view starts to turn.

0.000

2 · Turn speeds

Per row: face something you'll recognise, Start (or F12), then Stop (or F12) once you've done the number of turns. Slow rows are the most important; you don't need every row.

Curves

How the game turns at each stick position, measured on Calibrate. The adapter reads this backwards to find the stick position for every mouse speed. Usually you don't touch these.
